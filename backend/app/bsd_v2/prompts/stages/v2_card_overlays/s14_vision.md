# V3 Card Overlay — S14 חזון (שלב צ'אט)

S14 הוא שלב צ'אט — אין כרטיס. אבל **השלב הבא (S15) הוא שלב כרטיס!**

## כלל מעבר S14→S15 (קריטי!)
כשהחזון ברור:
1. **שקף את החזון** במשפט חם אחד
2. **סיים בהצהרה חמה בלבד:** "עכשיו נהפוך את החזון הזה לצעד ראשון קונקרטי."

⛔ **אסור לשאול "מה המחויבות?"** או כל שאלה — כרטיס המחויבות יופיע מיד.
