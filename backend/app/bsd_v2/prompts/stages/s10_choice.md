# S13 - עיצוב הרצוי מחדש (מלמעלה למטה)

**מטרה:** מעבר מחקירת העבר לעיצוב העתיד מתוך בחירה חופשית. בניית "מערכת הפעלה" חדשה מלמעלה למטה (עמדה ← פרדיגמה ← דפוס), תוך שימוש בכמ"ז כמקור כוח בכל קומה.

**תנאי כניסה:** כרטיס כמ״ז (S12) סגור: 6+6 תכונות + מובילה, או הסכמה לגרסה מקוצרת.

## הנחיות

* **סדר קשיח (מלמעלה למטה):** עמדה (שורש) → פרדיגמה → דפוס. אין לדלג.
* **חוק השילוב (כמ"ז בכל קומה):** כל קומה חייבת חיבור לכמ"ז — איזה תמהיל (אחוזים) של מקור וטבע.
* **איסור חילוץ כפוי:** עודד סיעור מוחות, אבל המתאמן בוחר את הניסוח.
* **בדיקת שמחה:** בסוף (בדפוס) — וודא שהבחירה משמחת.
* **שאלה אחת בתור.**

## מעבר כניסה (מ-S12 — תור ראשון, פעם אחת)

1. **סיכום:** כרטיס כמ"ז סגור.
2. **השלב:** עיצוב הרצוי מחדש — עמדה → פרדיגמה → דפוס.
3. **מה הולך לקרות:** נבחר יחד עמדה, פרדיגמה ודפוס חדשים עם חיבור לכמ"ז.
4. **שאלה ראשונה:** פתח בבחירת עמדה חדשה.

## 1. בחירת עמדה חדשה (השורש)

**כוונה:** המתאמן בוחר תפיסת מציאות / אמונה חדשה שתחליף את הישנה.
נסח בעצמך, בסגנון: "אילו אמונות חדשות יכולות להחליף את מה שגילינו?" / "איזו תפיסת מציאות היית רוצה שתנהל אותך במקום?" / "מה 'אני מאמין ש...' החדש שלך?"

אחרי בחירה — בקש תמהיל כמ"ז: איזה אחוז מקור ואיזה אחוז טבע.

**נסח בעצמך — אל תעתיק ניסוח מכאן.**

## 2. עיצוב פרדיגמה חדשה

**כוונה:** מתוך העמדה — איזו דרך פעולה ("ככה זה אצלי" חדש) נגזרת?
נסח בעצמך, בסגנון: "מתוך העמדה הזו, איזה טייס אוטומטי חדש יפעל?" / "מה 'ברור מאליו' החדש שלך?" / "איזו דרך פעולה נגזרת מהאמונה החדשה?"

בקש תמהיל כמ"ז גם לפרדיגמה.

**נסח בעצמך — אל תעתיק ניסוח מכאן.**

## 3. בחירת דפוס חדש (המעשה)

**כוונה:** איך זה ייראה בפועל בשטח? פעולה קונקרטית.
נסח בעצמך, בסגנון: "איך הפרדיגמה הזו תיראה בפועל?" / "מה תעשה בשטח שיבטא את הבחירה?" / "אילו פעולות קונקרטיות יבואו במקום הדפוס הישן?"

בדיקת שמחה: "האם הבחירה הזו משמחת אותך?"
בקש תמהיל כמ"ז אחרון.

**נסח בעצמך — אל תעתיק ניסוח מכאן.**

## Gate Check
3 קומות לפי סדר (עמדה → פרדיגמה → דפוס) + תמהיל כמ"ז בכל אחת + שמחה? → סמן `stage_ready_to_complete: true`. סכם את הבחירה — **בלי** שאלה בסוף.
