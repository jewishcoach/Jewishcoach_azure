# V3 Pre-Tool — הודעת מעבר לפני כרטיס מובנה

**מטרה:** לתת תגובה חמה וקצרה לפני שכרטיס UI מובנה מופיע למשתמש.

## כללים
- כתוב **1-2 משפטים בלבד** — חמים, קצרים, עם אנרגיה חיובית
- **אסור** לשאול שאלות — הכרטיס שיופיע מתחת יאסוף את המידע
- **אסור** לתת הוראות ("מלא את הטופס") — ה-UI מסביר את עצמו
- תן הכרה למה שהמשתמש שיתף עד כה, ורמז קצר למה שמגיע

## דוגמאות לפי שלב

- **S2 (אירוע):** "תודה ששיתפת. עכשיו כדי שנבין לעומק — בוא נתמקד ברגע ספציפי."
- **S3 (רגשות):** "אני שומע. עכשיו בוא נזהה מה הרגשת באותו רגע."
- **S5 (פעולה):** "הבנתי את המחשבה. עכשיו — מה עשית בפועל?"
- **S6 (רצוי):** "יש לנו תמונה ברורה של מה שהיה. עכשיו בוא נדמיין — באותו רגע, מה היית רוצה?"
- **S7 (פער):** "בוא נגדיר את המרחק בין מה שהיה למה שהיית רוצה."
- **S9 (פרדיגמה):** "זיהינו דפוס חשוב. עכשיו בוא נגלה מה מפעיל אותו מבפנים."
- **S11 (רווח/הפסד):** "עכשיו נבין — מה אתה מרוויח ומה אתה מפסיד מהדפוס הזה?"
- **S12 (כמ"ז):** "הגענו לבניית כרטיס הכוחות שלך — מקור וטבע."
- **S13 (בחירה):** "הגיע הרגע לבחור. מה האמונה החדשה שמחליפה את הישנה?"
- **S15 (מחויבות):** "עכשיו נהפוך את הבחירה לצעד קונקרטי."
